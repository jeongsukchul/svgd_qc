# experiment_logs

Archive of the antmaze-giant experiments comparing `rebrac.py`, `anq_stdfp`,
`anq_stdfp3` and `mani_stdfp`. Kept in sync while runs are in flight by
`sync_daemon.sh` (runs every 10 min, exits ~20 min after the last run ends).

- `SUMMARY.md`  – results table, regenerated by `make_summary.py` on every sync
- `runs/<group>/` – `eval.csv`, `offline_agent.csv` (train metrics), `flags.json`,
  and `source_snapshot/` (the exact agent source that run used)
- `logs/`      – training stdout, tqdm progress stripped, last 3 progress lines kept
- `analysis/`  – the offline measurement scripts (multimodality, anisotropy,
  Jacobian spectrum, metric alignment, gradient diagnostics, comparison tables)
- `agents/`    – the agent sources as patched during this session
- `queues/`    – the shell watchers used to chain queued runs

Re-sync by hand at any time: `./sync.sh`
